# 水印工坊 · Watermark Studio

一个纯前端、零依赖的批量图片加水印工具。单个 HTML 文件即全部功能，图片全程在浏览器本地处理，**不上传任何服务器，不联网**。

> 项目代号：`photo-waterland`

## 功能

- **批量处理**：支持 JPG / PNG / WebP，可一次多选或拖拽上传，支持「总览」网格视图切换
- **双水印图层**：文字层 + 图片层（推荐透明 PNG logo），两层可同时显示，独立控制显隐与编辑
- **文字样式**：4 种字体族、字号、字色、描边、投影、加粗、斜体，支持多行文本
- **位置与变换**：九宫格快速定位、边距、透明度、旋转（-90° ~ 90°），也可直接在画布上拖拽水印
- **平铺模式**：按网格铺满整图，横向 / 纵向间距可调，适合防搬运底纹
- **导出控制**：原图尺寸或限制最长边 2000 / 1600 / 1200；PNG 无损或 JPG（质量 95%，体积约 1/5）
- **批量下载**：一键打包 zip 导出全部处理结果

## 本地运行

无需构建、无需安装依赖，直接双击 `index.html`，或起一个静态服务器：

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```

## 部署

Vercel 静态托管，零配置：

```bash
vercel --prod
```

仓库根目录的 `vercel.json` 已配置 `cleanUrls`，访问路径不带 `.html`。

## 技术说明

- 单文件 HTML + 原生 JavaScript，无框架、无 CDN、无外部字体
- 预览与导出均基于 `<canvas>` 2D 绘制，所见即所得
- 水印位置以图片百分比存储，因此在不同分辨率、不同批次的图片上位置保持一致
